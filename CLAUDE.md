# Working notes for this repo

Repo of ACCESS-CI allocation requests for the Galaxy science gateway. See
[README.md](README.md) for layout and the current cycle's deadline.

## Rules

- `archive/` is **verbatim history** exported from Google Drive. Do not edit,
  reword, or "fix" anything in it. It is the record of what was actually
  submitted. New cycles get a new directory.
- Never invent a number. Usage statistics, SU counts, assembly counts, user
  counts, and publication counts all get checked by reviewers against prior
  reports. If a figure is not verified, leave a `TODO` marker rather than a
  plausible-looking value.
- Prior years' text is reused heavily and deliberately — the mission does not
  change year to year. But anything that reads as *unchanged since last year*
  in a place where progress was promised is a liability. Watch especially for
  justification sentences copied forward verbatim across three or more cycles.

## Writing style

Follow the scientific-manuscript conventions in the user's global CLAUDE.md:
active voice, first-person plural, em-dashes for asides, tool names in
backticks, Vancouver citations `[1]`, define abbreviations once. Reviewers read
many of these; lead each section with its point.

## Page limits are enforced

Main 10 / Progress 3 / Performance 5 / CV 2 each. The 2025 Progress Report
blew its limit on a publication list. Long lists belong in the References
document, which has no page limit, or as a link to the Zotero library.
