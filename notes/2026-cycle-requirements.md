## Required documents

From <https://allocations.access-ci.org/prepare-requests>:

| Document | Pages | Required |
| --- | --- | --- |
| Main Document | 10 | Yes |
| Progress Report | 3 | Renewals only — this is a renewal |
| Code Performance & Resource Costs | 5 | Yes |
| Curriculum Vitae | 2 per PI/co-PI | Yes |
| References | no limit | Optional (use it — frees Main Document space) |
| Special Requirements | 1 | Optional |

Main Document must address: Scientific Background, Research Objectives,
Resource Usage Plan, Justification of allocation amounts, Resource
Appropriateness, and Access to other CI resources.

Progress Report "should describe how the PI's current or prior allocation was
used and summarize findings or results," must explain significant deviations
from originally proposed usage, and if any resource was underutilized "should
briefly describe the reasons for the underutilization and any mitigation."

Code Performance & Resource Costs "should contain code performance timings,
resource usage details, and scaling information" sufficient to support the
calculation of the request.

CVs: two-page NSF or NIH format highly recommended.

## Review criteria

1. Appropriateness of Methodology
2. Appropriateness of Research Plan
3. Efficient Use of Resources

Plus intellectual merit alignment with supporting grants.

## Note on the Progress Report page limit

The 2025 Progress Report overran badly — the publication list alone ran to
~500 lines and the document itself says "Note that we could not fit all
publications into the required 3 pages!" For 2026 the publication list should
move to the optional References document (no page limit) or be cited by link
to the Zotero library, keeping the Progress Report itself within 3 pages.
